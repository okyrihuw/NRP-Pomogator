# Как удалить драйвер Interception

Если раньше ты ставил **Interception** (например, для AutoHotInterception, «мастера подбора»
из старых версий Помогатора или другого биндера) — его лучше удалить.

Причина: Interception ставится как **фильтр-драйвер клавиатуры и мыши** (`keyboard.sys`,
`mouse.sys`, издатель **Oblita**). Его находят и блокируют античиты многих игр, в том числе
встроенный античит MTA (кик `SD #4 BOT` / `AC #4`). Причём драйвер виден античиту независимо
от того, запущен ли сам биндер.

---

## 1. Проверить, установлен ли он

**Способ А — файлы драйверов:**

1. Открой `C:\Windows\System32\drivers`.
2. Найди `keyboard.sys` и `mouse.sys`.
3. Правый клик → «Свойства» → вкладка «Подробно» → поле «Издатель».
   Если там **Oblita** / *Francisco Lopes da Silva* — это Interception.

**Способ Б — диспетчер устройств:**

1. `Win+X` → «Диспетчер устройств».
2. Раздел «Клавиатуры» → правый клик по своей клавиатуре → «Свойства» → «Драйвер».
3. Если в списке есть `keyboard.sys` от Oblita — драйвер стоит.

---

## 2. Удалить

1. Найди распакованный архив `Interception` (в нём есть папка `command line installer`).
   Если архива нет — скачай: <https://github.com/oblitum/Interception/releases> → `Interception.zip`.
2. Открой **командную строку от имени администратора**:
   `Win` → набери `cmd` → правый клик → «Запуск от имени администратора».
3. Перейди в папку установщика. Проще всего: открой её в проводнике, кликни в адресную
   строку, скопируй путь, затем в консоли напиши `cd ` (с пробелом) и вставь путь через
   правый клик → «Вставить».
4. Выполни:

   ```bat
   install-interception.exe /uninstall
   ```

5. **Перезагрузи компьютер.**

### Если выдаёт ошибку

Известная особенность — файл драйвера занят:

```
Error deleting \system32\drivers\keyboard.sys
```

Тогда, **не перезагружаясь между командами**:

```bat
install-interception.exe /install
install-interception.exe /uninstall
```

и только потом перезагрузись. Если и это не помогло — повтори те же две команды в
безопасном режиме Windows (вариант «Сеть»), затем перезагрузись обычным образом.

---

## 3. Проверить результат

1. Файлы `keyboard.sys` / `mouse.sys` с издателем Oblita пропали.
2. Диспетчер устройств → «Клавиатуры» → у клавиатуры снова драйвер Microsoft
   (`kbdclass.sys`).
3. Зайди в игру — кик `SD #4 BOT` не должен повторяться.

Клавиатура и мышь после удаления работают как обычно: это фильтр, а не замена драйвера.
Если после перезагрузки ввод пропал (бывает редко, при кривом удалении) — зайди в безопасный
режим, выполни `/install` и `/uninstall` ещё раз.
