# История версий

## 1.0 — первый публичный релиз

Биндер-буфер для админки GTA (MTA / NextRP).

**Что делает**
- бинд кладёт готовую команду в буфер обмена; вставку `Ctrl+V` и `Enter` делает человек;
- плашка «СКОПИРОВАНО В БУФЕР» и звук (каждое отключается в конфиге отдельно);
- команды со слэшем — вставляются и в чат, и в репорт;
- `{space}` на конце (`/get{space}` → `/get `), переменные `{my_id}`, `{Пол}`, `{nick}`, `{rank}`;
- окошко с подсказками (`Alt+P`), значок в трее;
- конфиг `binds.ini` правится Блокнотом, «Обновить» в трее перечитывает его без перезапуска.

**Чего нет**
- автоматической печати в игру (`SendInput` не вызывается ни разу);
- драйверов, внедрения в игру, прав администратора;
- настройки `Win+V`: команды **не попадают** в историю буфера и в облако.

**Подтверждение бинда настраивается по отдельности**
- `copy_toast = true` — плашка «СКОПИРОВАНО В БУФЕР» (по умолчанию включена);
- `copy_beep = true` — звук (по умолчанию включён);

любую из двух можно выключить, вторая продолжит работать.

**Настройки `[settings]`:** `nick`, `rank`, `my_id`, `copy_toast`, `copy_toast_ms`,
`copy_beep`, `copy_no_history`, оформление окошка, `toggle_hint`, `only_when_window`,
`tray_notify_on_start`.

**Бинды:** `key` / `group` / `hint` / `send`.
